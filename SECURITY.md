# Security Policy

## Supported versions

Security fixes are applied to the latest code on `main`. Older commits and forks are not maintained by this project.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Email `info@nabeel.io` with:

- A description of the issue and its impact
- Steps to reproduce with synthetic or redacted data
- The affected operating system and Node.js version
- Any suggested mitigation, if known

Avoid sending real Codex sessions, credentials, proprietary source code, or other sensitive information. We aim to acknowledge reports within seven days and will coordinate disclosure after a fix is available.

Security-sensitive areas include path handling, unintended modification of source sessions, exposure of transcript data, unsafe PDF input handling, and vulnerable dependencies.
